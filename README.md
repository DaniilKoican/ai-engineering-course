## Troubleshooting

### 'ascii' codec can't encode characters`
**Что видел:** ошибка "оба провайдера недоступны"
**Почему:** был использован неверный ключ гигачат
**Что сделал:** вернул настоящий ключ и дописал fallback в код, чтобы ответил другой провайдер
